# TabSanté — portail et site de présentation

Vitrine publique de TabSanté, plateforme des soins infirmiers à domicile (IDEL). Le code de l'application est privé.

- **Portail d'aide et de documentation** (racine) : guides du poste fixe et du terminal, aide écran par écran, FAQ, glossaire, documentation technique.
- **Site de présentation** (`/site/`) : version de travail, non indexée tant que les informations légales ne sont pas complètes.

Données de démonstration entièrement fictives. Généré depuis le dépôt de l'application (`docs/portail`, `site/`).
